## 什麼是工具使用？

**工具使用（tool use）**，也叫做**函式呼叫（function calling）**，指的是透過定義和呼叫外部工具或函式，來**擴充 Claude 能力**的方法。我們可以讓 Claude 使用一組預先定義好的工具，它可以在任何時候呼叫這些工具。工具讓我們能寫程式碼，執行 Claude 原本做不到的特定任務或計算。簡單來說：**工具使用是增強 Claude 功能的一種方式。**

![工具使用的例子](../../tool_use/images/tool_use_examples.png)

> 🧩 **白話小補充**：Claude 很聰明，但它被關在「一個房間」裡：不能上網查即時資訊、不能幫你寄信、不能查你公司的資料庫、算大數字也可能算錯。**工具**就像給它一支電話：它可以打電話請你（你的程式）幫忙查股價、查資料庫、寄信，再根據結果回答。

## 為什麼這很重要？

工具使用是一個**改變遊戲規則**的功能，它釋放了 Claude 真正的潛力，開啟了充滿可能性的世界。它是能大幅提升應用程式價值和影響力的關鍵元件。

* **擴充 Claude 的能力**
  * 工具使用讓你能把 Claude 的能力擴充到它的內建功能之外。透過定義和呼叫外部工具，你可以讓 Claude 執行它原本做不到的任務。這代表你可以打造更強大、更多用途的應用程式，處理更廣泛的使用者需求。
* **和你現有的系統整合**
  * 工具使用讓 Claude 能和你現有的系統、資料庫或 API 無縫整合。你可以定義和後端服務互動、從資料庫取得資料，或在應用程式中觸發動作的工具。這種整合讓你在使用現有基礎設施和資料的同時，也能發揮 Claude 的力量。
* **自動化複雜的任務**
  * 有了工具使用，你可以把包含多個步驟、或需要特殊計算的複雜任務和工作流程自動化。透過定義封裝這些任務的工具，你可以簡化流程、減少人工、提升效率。Claude 可以根據使用者的輸入或預先定義的條件，聰明地在對的時間呼叫對的工具。
* **提升使用者體驗**
  * 工具使用可以大幅提升應用程式的使用者體驗。讓 Claude 使用相關的工具，就能讓它對使用者的問題提供更準確、更貼近情境、更個人化的回答。使用者可以用自然語言和你的應用程式互動，而 Claude 可以利用工具提供豐富的資訊，或代替使用者執行想要的動作。
* **擴展和客製化**
  * 有了工具使用，你可以擴展和客製化你的應用程式，滿足使用者不斷變化的需求。隨著使用者增加或需求改變，你可以很容易地加入新工具或修改現有的工具，擴充 Claude 的能力。這種彈性讓你能快速調整和反覆改進，確保應用程式保持實用和競爭力。

## 使用情境範例

我們在使用工具使用的客戶中，看到的一些常見主題包括：

* **取得資訊**
  * 工具可以用來從外部來源取得資料，例如資料庫、API 或網路服務。例如，一個工具可以根據使用者的輸入，取得天氣資訊、股價或新聞文章。
* **執行計算**
  * 工具可以執行可能超出 Claude 內建能力的複雜計算或數學運算，包括財務計算、科學運算或統計分析。
* **處理資料**
  * 工具可以用來處理、轉換或操作各種格式的資料，包括資料格式化、資料擷取或資料轉換等任務。
* **和外部系統互動**
  * 工具可以幫助和外部系統或服務互動，例如寄送電子郵件、觸發通知，或控制物聯網（IoT）裝置。
* **產生內容**
  * 工具可以根據使用者的輸入或預先定義的範本，協助產生特定類型的內容，例如圖片、圖表或排版好的文件。

更具體的可能使用情境包括：

* **企業資料整合**：把 Claude 和 CRM（顧客關係管理）、ERP（企業資源規劃）、ITSM（IT 服務管理）等企業系統整合，取得顧客資料、自動化工作流程，並提供個人化的支援。
* **財務分析和報告**：用 Claude 和工具分析財務資料、產生投資報告、評估風險，並確保符合法規。
* **醫療診斷和治療規劃**：把 Claude 和電子病歷（EHR）以及醫學知識庫整合，協助醫療專業人員做出明智的決定，並制定個人化的治療計畫。
* **教育家教和內容創作**：結合 Claude 和教育資源與工具，提供個人化的家教、產生學習教材，並適應每個人的學習風格。
* **法律文件分析和審閱**：用 Claude 和工具分析法律文件、擷取關鍵資訊、找出潛在問題，並產生摘要，簡化法律流程。
* **客服自動化**：把 Claude 和知識庫以及客服工單系統整合，提供自動化的客服、排除問題，並縮短回應時間。
* **銷售和行銷自動化**：結合 Claude 和工具分析顧客資料、產生個人化的行銷內容、篩選潛在客戶，並優化銷售流程。
* **軟體開發協助**：把 Claude 和 IDE（整合開發環境）、版本控制系統以及專案管理工具整合，協助開發者寫程式、找出錯誤，並管理軟體專案。
* **研究和創新**：利用 Claude 和工具進行市場研究、分析專利資料、產生新點子，推動各產業的創新。
* **內容創作和優化**：用 Claude 和工具為各種平台（包括網站、社群媒體和行銷活動）產生、優化和個人化內容。

## 工具使用是怎麼運作的

我們來看看工具使用實際上是怎麼運作的。一開始最重要的是要了解：**Claude 本身並不會「執行」任何程式碼。** 我們告訴 Claude 有一組它可以「請我們呼叫」的工具，然後**真正執行工具程式碼、並把結果告訴 Claude 的，是我們**。

注意，Claude 沒有任何內建的伺服器端工具可以使用。所有的工具都必須由你（使用者）在每次 API 請求中明確提供。這代表：由你定義可用的工具（附上清楚的描述和輸入格式），也由你實作和執行工具的邏輯（例如在 Claude 要求時執行某個特定的函式或查詢某個 API）。這讓你對 Claude 能使用的工具有完全的控制權和彈性。

> 🔄 **2026 更新**：「Claude 沒有任何內建的伺服器端工具」是 2024 年的說法。現在 Anthropic 也提供一些**由 Anthropic 伺服器執行的工具**（例如網路搜尋、網頁擷取、程式碼執行），只要在 `tools` 裡宣告就能使用，不需要你自己執行。不過這個單元教的是最基本、也最常用的「**自訂工具**」——由你定義、由你執行，觀念完全適用。

![資料庫工具的運作流程](../../tool_use/images/db_tool.png)

具體來說，在 Claude 上使用工具包含下面這些步驟：

1. **提供 Claude 工具和使用者提示詞**：（API 請求）
    * 定義你想讓 Claude 使用的一組工具，包括它們的**名稱、描述和輸入格式（input schema）**。
    * 提供一個可能需要用到其中一個或多個工具才能回答的使用者提示詞，例如「我用 500 美元可以買幾股通用汽車？」

2. **Claude 使用工具**：（API 回應）
    * Claude 評估使用者的提示詞，判斷可用的工具中有沒有能幫上使用者問題或任務的。如果有，它也會決定要用哪個（哪些）工具、輸入什麼。
    * Claude 輸出一個格式正確的**工具使用請求**。
    * API 回應的 `stop_reason` 會是 **`tool_use`**，表示 Claude 想使用一個外部工具。

3. **擷取工具輸入、執行程式碼、回傳結果**：（API 請求）
    * 在客戶端（你的程式）這邊，你要從 Claude 的工具使用請求中擷取出**工具名稱和輸入**。
    * 在客戶端執行真正的工具程式碼。
    * 繼續這段對話，送出一則新的使用者訊息，裡面包含一個 **`tool_result`（工具結果）內容區塊**，把結果回傳給 Claude。

4. **Claude 使用工具結果組織回答**：（API 回應）
    * 收到工具結果之後，Claude 會用這些資訊，針對原本的使用者提示詞組織出最終的回答。

第 (3) 和第 (4) 步是**選擇性的**——在某些工作流程中，「Claude 使用了工具」這件事本身就是你需要的全部資訊，你可能不需要把工具結果回傳給 Claude。之後的章節會再詳細說明。

> 🧩 **白話小補充：用「點外送」來比喻這 4 步**
> 1. 你給助理（Claude）一份「外送菜單」（工具清單）和客人的需求（使用者問題）。
> 2. 助理看完說：「請幫我打給『股價查詢』這家店，點『通用汽車』。」（工具使用請求，`stop_reason = "tool_use"`）
> 3. 你真的打電話去點，拿到結果「每股 43.09 美元」，交給助理。（`tool_result`）
> 4. 助理算一算，回答客人：「你大約可以買 11 股。」（最終回答）

{

#### 第 1 步：提供 Claude 工具和使用者提示詞（API 請求）

接著，我們需要定義 `get_stock_price` 工具的**名稱、描述和輸入格式**。我們之後會花更多時間在「定義工具」上，但這裡先給一個假想的 `get_stock_price` 工具定義，讓我們可以告訴 Claude：

```python
tool_definition = {
    "name": "get_stock_price",
    "description": "Retrieves the current stock price for a given company",
    "input_schema": {
        "type": "object",
        "properties": {
            "company": {
                "type": "string",
                "description": "The company name to fetch stock data for"
            }
        },
        "required": ["company"]
    }
}
```

**白話解讀這個工具定義：**
- `"name"`：工具名稱 `get_stock_price`。
- `"description"`：工具說明——「取得某家公司目前的股價」。Claude 會根據這段說明判斷**什麼時候**該用這個工具。
- `"input_schema"`：輸入格式（用一種叫 **JSON Schema** 的格式描述）：
  - `"type": "object"`：輸入是一個物件（字典）。
  - `"properties"`：裡面有哪些欄位——只有一個 `company`（公司），型別是字串，說明是「要查詢股票資料的公司名稱」。
  - `"required": ["company"]`：`company` 是**必填**的。

接著，我們會告訴 Claude 有這個工具，並送出一個可能需要用到這個工具的提示詞：

```python
response = client.messages.create(
    model="claude-opus-4-6",
    messages=[{"role": "user", "content": "How many shares of General Motors can I buy with $500?"}],
    max_tokens=500,
    tools=[tool_definition]
)
```

（重點是新增的 `tools=[tool_definition]` 參數：把工具清單傳給 Claude。使用者問的是「我用 500 美元可以買幾股通用汽車？」原課程的模型是 `claude-3-opus-20240229`，已停用。）

#### 第 2 步：Claude 使用工具（API 回應）

Claude 收到 API 請求，評估使用者的提示詞。它判斷 `get_stock_price` 工具會有助於回答關於購買通用汽車股票的問題。

Claude 回應一個格式正確的工具使用請求。我們之後會深入介紹，但這裡先給一個 Claude 表示它「想」使用我們工具的回應範例：

```python
{
  "stop_reason": "tool_use",
  "tool_use": {
    "name": "get_stock_price",
    "input": {
      "company": "General Motors"
    }
  }
}
```

（這是簡化過的示意：`stop_reason` 是 `"tool_use"`，表示 Claude 想用工具；它想用的工具是 `get_stock_price`，輸入是 `{"company": "General Motors"}`。真正的回應格式會在下一課看到。）

#### 第 3 步：擷取工具輸入、執行程式碼、回傳結果（API 請求）

在客戶端，我們從 Claude 的工具使用請求中擷取出工具名稱（`get_stock_price`）和輸入的公司名稱（`General Motors`）。

我們用從 Claude 的工具請求中擷取出的輸入，執行真正的 `get_stock_price` 函式，從 API 取得即時的股市資料。這個函式可能會回傳像這樣的資料：

```python
{
  "symbol”: “GM”, 
  "price”: 43.09
}
```

接著，我們把工具的結果告訴 Claude。我們繼續這段對話，送出一則包含 `tool_result` 內容區塊的新使用者訊息，把股價工具的結果回傳給 Claude（之後會詳細介紹）。

#### 第 4 步：Claude 使用工具結果組織回答（API 回應）

Claude 收到股價工具的結果，把即時的股市資訊融入它對原本使用者提示詞的最終回答中，最後回應類似這樣的內容：

>It looks like with a current share price of $43.09, you can buy around 11 shares of General Motors stock with your $500.
>（看起來以目前每股 43.09 美元的股價，你用 500 美元大約可以買 11 股通用汽車的股票。）

## 📌 重點整理

- **工具使用（函式呼叫）**：讓 Claude 可以「請你的程式」幫忙做它做不到的事（查即時資料、計算、操作外部系統⋯⋯）。
- **Claude 不會自己執行程式碼**——它只會說「我想用哪個工具、輸入是什麼」，**真正執行的是你的程式**。
- 定義一個工具需要：**名稱（name）**、**描述（description）**、**輸入格式（input_schema，JSON Schema）**。
- 流程四步：① 送出工具清單 + 問題 → ② Claude 回應工具使用請求（`stop_reason = "tool_use"`）→ ③ 你執行工具，用 `tool_result` 回傳結果 → ④ Claude 根據結果回答。第 ③④ 步有時可以省略。

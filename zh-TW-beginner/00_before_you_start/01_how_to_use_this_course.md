## 這套課程到底在教什麼？

一句話：**教你怎麼用程式（Python）去「指揮」Claude 這個 AI 幫你做事。**

你平常可能在網頁上跟 ChatGPT 或 Claude 聊天。那是用「聊天視窗」跟 AI 溝通。
這套課程要教的是另一種方式：**寫幾行程式，讓你的程式直接跟 Claude 對話**。
這樣做的好處是可以「自動化」——例如一次請 Claude 幫你分類 1000 封客服信、自動摘要每一通電話錄音、做一個能查資料庫的聊天機器人。

原本的英文課程由 Anthropic（開發 Claude 的公司）製作，共有 **5 門課**。這個「新手白話版」把全部內容翻成中文，並且：

- ✅ **內容完整保留**：每一段說明、每一格程式碼、每一個練習都在，沒有刪減。
- ✅ **用白話解釋**：專有名詞第一次出現時會解釋；看起來很嚇人的程式碼會一行一行拆開講。
- ✅ **補上新手需要的背景知識**：原課程假設你已經會 Python，這裡多了一份「Python 速成」。
- ✅ **程式碼可以直接跑**：原課程用的 Claude 3 模型已經停用了，這裡已經幫你換成現在還能用的模型（詳見 [0-3 準備你的電腦](03_setup_your_computer.md)）。

## 每一課長什麼樣子？

每一課都會有這幾個部分：

1. **🎯 這一課你會學到**：先告訴你目標，讓你知道重點在哪。
2. **正文**：原課程內容的白話翻譯。
3. **💻 程式碼格**：可以執行的程式碼。很多程式碼下面會有「**逐行解說**」。
4. **▶ 原課程執行結果**：原作者執行程式時得到的結果，讓你就算不執行也看得懂。
   （⚠️ Claude 每次的回答都不太一樣，而且我們換了新模型，所以你自己跑出來的文字**一定**會不同，這是正常的！）
5. **🧩 白話小補充 / 💡 小提醒 / ⚠️ 注意**：額外加上的新手說明（原課程沒有，是這個版本補充的）。
6. **✏️ 練習**：原課程的練習題，題目翻成中文。
7. **📌 重點整理**：每課最後用幾句話幫你複習。

> 📝 **怎麼分辨哪些是原課程內容、哪些是補充？**
> 用「🧩 白話小補充」、「💡 小提醒」、「⚠️ 注意」、「📌 重點整理」、「🔄 2026 更新」這些標記開頭的段落，是這個新手版額外加的。其餘的正文是原課程內容的翻譯。

## 每一課有兩種檔案，要開哪一個？

每一課都有兩個同名檔案：

| 檔案 | 適合誰 | 怎麼開 |
|---|---|---|
| `xxx.md` | 只想「閱讀」的人 | 直接在 GitHub 網頁上點開就能讀，手機也可以 |
| `xxx.ipynb` | 想「動手執行程式」的人 | 用 Jupyter Notebook 或 VS Code 打開（安裝方法見 [0-3](03_setup_your_computer.md)） |

兩個檔案的內容是**一模一樣**的，只是格式不同。建議：**第一次先用 `.md` 讀懂，再打開 `.ipynb` 實際跑一次。**

## 遇到看不懂的地方怎麼辦？

1. **先查 [名詞小辭典](../GLOSSARY.md)**：所有專有名詞都有白話解釋。
2. **看不懂程式碼語法**：回去翻 [0-4 Python 速成](04_python_crash_course.md)。
3. **程式出現紅色錯誤訊息**：看 [0-3 準備你的電腦](03_setup_your_computer.md) 最後面的「常見錯誤排除」。
4. **還是不懂**：把錯誤訊息或看不懂的段落複製下來，直接問 Claude！（這也是很好的練習）

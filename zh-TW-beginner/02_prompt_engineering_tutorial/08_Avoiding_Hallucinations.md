## 🎯 這一章你會學到

- 什麼是 AI 的「**幻覺（hallucination）**」
- 技巧 1：**給 Claude 一條退路**——允許它說「我不知道」
- 技巧 2：**先找證據再回答**——請 Claude 先從文件中擷取相關引文
- 加碼：降低 `temperature`

> 🧩 **白話小補充：什麼是「幻覺」？** 就是 AI 一本正經地胡說八道——講出聽起來很像真的、但其實是錯的或編造出來的內容。原因是 LLM 的本質是「接話」，有時候為了給出一個「看起來很有幫助」的答案，就會自己編出來。

```python
import re
import anthropic

# Retrieve the API_KEY & MODEL_NAME variables from the IPython store
%store -r API_KEY
%store -r MODEL_NAME

client = anthropic.Anthropic(api_key=API_KEY)

def get_completion(prompt: str, system_prompt="", prefill=""):
    message = client.messages.create(
        model=MODEL_NAME,
        max_tokens=2000,
        temperature=0.0,
        system=system_prompt,
        messages=[
          {"role": "user", "content": prompt},
          {"role": "assistant", "content": prefill}
        ]
    )
    return message.content[0].text
```

壞消息是：**Claude 有時候會「產生幻覺」，說出不真實或沒有根據的內容。** 好消息是：有一些技巧可以把幻覺降到最低。

下面我們會介紹其中幾種技巧，也就是：
- 給 Claude 一個「可以說自己不知道答案」的選項
- 請 Claude 在回答之前先找證據

不過，**避免幻覺的方法有很多**，包括很多你在這門課裡已經學過的技巧。如果 Claude 產生了幻覺，試試看多種不同的技巧，讓 Claude 提高準確度。
